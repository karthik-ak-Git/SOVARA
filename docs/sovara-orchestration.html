SOVARA orchestration — skills, tools & MCPs on a sovereign paved road

One prompt enters the Interaction zone, is classified and routed in Orchestration, fans out through a governed Execution Fabric (skills hydrate the prompt, tools execute locally, MCPs are invoked only if loopback-registered), and replies are persisted as an append-only event log. The loopback guard is the privileged gate: permitted ingress to 127.0.0.1/localhost only; every other host terminates at the trust boundary.

How a prompt flows

Orchestration sequence

  • Classify → route: TaskClassifier tags intent; ModelRouter picks local model by VRAM/capability.
  • Skills hydrate, tools execute: .opencode/skills/* inject prompt fragments; Tool Kernel runs read/bash/edit/glob/grep/task locally.
  • Persist then stream: every turn appends to events.v1.jsonl (seq-contiguous); UI streams reply + artifacts.

Where controls are enforced

Secure paved road

  • Permitted: User → AppBackend → HttpClient → Local Runtime on 127.0.0.1/localhost/::1 only.
  • Blocked: external host terminates at trust boundary ✕ before the gate; DNS verified, redirects re-validated.
  • Privileged gate: HttpClient — timeout + size caps, bodies never logged, secrets never persisted.

What is aggregated
