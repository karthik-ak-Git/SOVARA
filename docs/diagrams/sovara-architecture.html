Sovara desktop architecture

Desktop-only Electron architecture: React renderer, narrow preload boundary, TypeScript main process, and local inference.

React renderer

  • Chat and composer
  • Models and library
  • Settings and context
  • Light design tokens

Electron main

  • Zod-validated IPC
  • AppBackend
  • SQLite + JSONL
  • Tools and permissions

Local inference

  • llama.cpp runtime
  • GPU/CPU placement
  • Loopback health check
  • Verified readiness

Trust boundary: context isolation, preload allowlist, no raw ipcRenderer, and explicit external web access. There is no hosted web app or Python sidecar.
